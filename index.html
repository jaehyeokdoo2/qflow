Flow-based policies are expressive but unstable to optimize. Q-Flow resolves this by learning value along the intermediate latent states of the flow, enabling stable policy improvement without ever backpropagating through the ODE solver. Abstract

There is growing interest in utilizing flow-based models as decision-making policies in reinforcement learning due to their high expressive capacity. However, effectively leveraging this expressivity for value maximization remains challenging, as naive gradient-based optimization requires backpropagating through numerical solvers and often leads to instability. Existing approaches typically address this by restricting policy expressivity, resulting in a trade-off between optimization stability and representational flexibility.

We introduce Q-Flow, a framework that leverages the deterministic nature of flow dynamics to explicitly propagate terminal trajectory value to intermediate latent states along the policy-induced flow. This formulation enables stable policy optimization using intermediate value gradients without unrolling the numerical solver — effectively bridging the gap between stability and expressivity.

Challenge: The Expressivity–Stability Dilemma

Flow-based policies can model complex, multimodal action distributions that simpler policies cannot. But optimizing them for reward requires backpropagating gradients through a numerical ODE solver — an operation that is both expensive and unstable. Prior methods escape this by giving something up:

FBRAC

Keeps full expressivity via BPTT, but becomes numerically unstable when behavior cloning constraints weaken.

Expressive · Unstable

FQL

Achieves stability through one-step distillation into a student policy, but loses the representational power of flow models.

Stable · Limited

Method

Q-Flow treats action generation as a hierarchical MDP: an outer environmental MDP over states and actions, and an inner continuous-time flow MDP over the latent trajectory $x_\tau \in [0,1]$ that generates each action $a = x_1$.

1 Flow-Consistent Value

Because the flow is deterministic, any intermediate latent state $x_\tau$ always integrates to the same terminal action $x_1$. The value at an intermediate state is therefore identical to the value at its terminal action:

$$V^\pi(s,\, x_\tau,\, \tau) \;:=\; Q\!\left(s,\; \Psi^\pi_{1,\tau}(x_\tau, s)\right)$$

Q-Flow learns this intermediate value function $V^\pi_\omega$ by regressing against a target outer critic $Q_{\bar\phi}$ evaluated at the rolled-out terminal state. This gives each latent waypoint a meaningful value estimate — without full ODE rollouts at training time.

Deterministic path → value is invariant along the trajectory

2 Intermediate Value Gradient Matching

Instead of backpropagating through the solver, Q-Flow steers the velocity field directly using gradients of $V^\pi_\omega$ at each intermediate state. The policy is trained to match a value-guided target velocity:

$$v_{\text{target}} \;=\; (x_1 - x_0) \;+\; \frac{1}{\lambda}\,\nabla_{x_\tau} V^\pi_\omega(s,\, x_\tau,\, \tau)$$

The guidance coefficient $\lambda$ controls how far the policy deviates from the dataset distribution. Crucially, $V^\pi_\omega$ is trained on dataset paths — so its gradients are reliable without any ODE unrolling.

Results

We evaluate on OGBench — a challenging suite spanning navigation, locomotion, manipulation, and puzzle tasks.

Standard Setting

Q-Flow achieves an average score of 54.4, outperforming FQL (43.8) by +10.6 pp and consistently leading across all task categories. Largest gains: +31 pp on antmaze-giant, +25 pp on humanoidmaze-medium, +19 pp on puzzle-3x3.

Offline-to-Online Adaptation

Q-Flow requires no architectural changes for online fine-tuning. Across 5 OGBench environments, it achieves a +23% average improvement over FQL during online adaptation while preserving its offline performance.
