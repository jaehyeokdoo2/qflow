Flow-based models are compelling policy representations for offline RL — they can capture complex, multimodal action distributions that simpler policies miss. But optimizing them for reward via backpropagation through a numerical ODE solver is computationally expensive and numerically unstable, forcing prior work to sacrifice either expressivity (FQL) or stability (FBRAC).

Q-Flow escapes this dilemma by exploiting a key property of flow models: their dynamics are deterministic, so every intermediate latent state $x_\tau$ is uniquely coupled to a terminal action $x_1$. We use this invariance to learn value functions directly over intermediate states, and steer the velocity field with their gradients — achieving stable, expressive policy optimization without ever unrolling the solver.

Challenge: The Expressivity–Stability Dilemma

Flow-based policies can model complex, multimodal action distributions that simpler policies cannot. But optimizing them for reward requires backpropagating gradients through a numerical ODE solver — an operation that is both expensive and unstable. Prior methods escape this by giving something up:

Backprop Through Time (BPTT)

Keeps full expressivity by directly backpropagating through the ODE solver, but becomes numerically unstable when behavior cloning constraints weaken.

High Expressivity · Unstable Optimization

One-Step Distillation

Achieves stability by distilling the flow into a one-step student policy, but loses the representational power of flow models.

Low Expressivity · Stable Optimization

Method

Q-Flow treats action generation as a hierarchical MDP: an outer environmental MDP over states and actions, and an inner continuous-time flow MDP over the latent trajectory $x_\tau \in [0,1]$ that generates each action $a = x_1$.

1 Flow-Consistent Value

Because the flow is deterministic, any intermediate latent state $x_\tau$ always integrates to the same terminal action $x_1$. The value at an intermediate state is therefore identical to the value at its terminal action:

$$V^\pi(s,\, x_\tau,\, \tau) \;:=\; Q\!\left(s,\; \Psi^\pi_{1,\tau}(x_\tau, s)\right)$$

Q-Flow learns this intermediate value function $V^\pi_\omega$ by regressing against a target outer critic $Q_{\bar\phi}$ evaluated at the rolled-out terminal state. This gives each latent waypoint a meaningful value estimate — without full ODE rollouts at training time.

Deterministic path → value is invariant along the trajectory

2 Intermediate Value Gradient Matching

Instead of backpropagating through the solver, Q-Flow steers the velocity field directly using gradients of $V^\pi_\omega$ at each intermediate state. The policy is trained to match a value-guided target velocity:

$$v_{\text{target}} \;=\; (x_1 - x_0) \;+\; \frac{1}{\lambda}\,\nabla_{x_\tau} V^\pi_\omega(s,\, x_\tau,\, \tau)$$

The guidance coefficient $\lambda$ controls how far the policy deviates from the dataset distribution. Crucially, $V^\pi_\omega$ is trained on dataset paths — so its gradients are reliable without any ODE unrolling.

Results

We evaluate on OGBench1 — a challenging suite spanning navigation, locomotion, manipulation, and puzzle tasks.

Standard Setting

Q-Flow achieves an average score of 54.4, outperforming FQL (43.8) by +10.6 pp and consistently leading across all task categories. Largest gains: +31 pp on antmaze-giant, +25 pp on humanoidmaze-medium, +19 pp on puzzle-3×3.

+ Advanced Offline RL Techniques

Following the advanced evaluation protocol introduced in QAM3, we combine Q-Flow with three complementary offline RL techniques: ensemble critics (10 critics for more stable value estimates), pessimistic value backup (lower confidence bound to penalize out-of-distribution actions), and action chunking (predicting a sequence of future actions at each step). Under this harder protocol, Q-Flow achieves 47.5 on average, outperforming the strongest baseline QAM-E (44.8) by +2.7 pp.

Offline-to-Online Adaptation

Q-Flow requires no architectural changes for online fine-tuning. Across 5 OGBench1 environments, it achieves a +23% average improvement over FQL2 during online adaptation while preserving its offline performance.
