Challenge: Offline RL Dilemma

Offline reinforcement learning faces a fundamental challenge: learning optimal policies from fixed datasets without interaction with the environment. The key challenges are:

  • Distribution Shift — The learned policy may diverge from the behavior policy, leading to poor generalization on out-of-distribution actions.
  • Data Quality Heterogeneity — Real datasets contain trajectories of varying quality, from near-optimal to random exploration.
  • Value Extrapolation Error — Standard value function approximation can lead to overestimation on unseen state-action pairs.

QFlow: Quality-Weighted Policy Learning

QFlow addresses these challenges through a novel approach that explicitly incorporates trajectory quality signals into the learning process. The key innovation lies in:

Quality-Weighted Learning Mechanism: We weight learning signals by estimated trajectory quality, allowing the agent to learn preferentially from high-quality data while remaining robust to poor quality samples.

Advanced Policy Optimization: QFlow combines quality-aware learning with state-of-the-art policy optimization techniques to ensure stable convergence and efficient training.

Flexible Agent Architecture: The framework supports multiple underlying RL algorithms (IQL, FBRAC, FQL, etc.), allowing practitioners to choose the right tool for their specific problem.

Getting Started

Installation

git clone https://github.com/yourusername/qflow.git
cd qflow
pip install -r requirements.txt

Quick Start

python main.py --env_name=antmaze-medium-play-v2 --agent=agents/qflow.py

Configuration

QFlow hyperparameters are managed in qflow_config.py. Per-domain configurations are automatically loaded based on the environment name.
